# Polices

- **Noto Sans** (Regular, Medium, Bold) : SIL Open Font License 1.1, texte complet dans `OFL.txt`.
- **ChicagoFLF** : version libre de la police Chicago des premiers iPods, par Robin Casady, placée par son
  auteur dans le domaine public (catalogue de la Font Library : https://fontlibrary.org/en/font/chicagoflf).
  Le fichier porte encore une mention « (c) Richard A. Ware » héritée de Casady & Greene ; les droits des
  polices FLF sont revenus à leurs auteurs à la fermeture de la société.
